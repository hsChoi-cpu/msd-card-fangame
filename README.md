# 심연 레이드 — 웹 브라우저 턴제 카드 전투 프로토타입

## 실행 방법

1. ZIP 파일을 압축 해제합니다.
2. `index.html` 파일을 Chrome, Edge 등 최신 브라우저로 엽니다.
3. 외부 라이브러리, 서버, 인터넷, 계정이 필요하지 않습니다.

## 조작

1. 아군 캐릭터의 행동 슬롯을 클릭합니다.
2. 화면 아래 해당 캐릭터의 손패에서 카드를 클릭합니다.
3. 보스의 예고 행동 슬롯을 클릭하면 그 행동과 **합 또는 직접 수비 대응**을 진행합니다. 다른 아군을 향한 공격을 가로채려면 자신의 슬롯 속도가 보스 슬롯 속도보다 높아야 합니다. 자기 자신에게 향한 공격은 속도 제한 없이 대응할 수 있습니다.
4. 합을 원하지 않으면 '보스 본체' 버튼을 누릅니다. 공격 카드는 보스에게 일방 공격하고, 방어·회피·반격 카드는 자신에게 발동합니다.
5. 전투 실행을 누르고 로그를 확인한 뒤 다음 턴으로 진행합니다.

## 현재 구현한 시스템

- 3명의 아군을 혼자 조작, 아군별 8장 고정 덱, 2개 행동 슬롯, 매 턴 4장 드로우 / 버림 / 재셔플
- 보스 1명, 행동 예고 3~4개, 슬롯별 랜덤 속도, HP 50%에서 2페이즈 전환
- 공격 합: 위력 비교, 패자의 공격 취소, 동률 시 양쪽 취소
- `사용 시` 효과가 적용된 이후 합 위력 계산, `합 승리/패배 시` 효과 이후 **피해 직전 위력 재계산**
- 공격력/방어력/공통 위력 증가·감소, 보호·취약 각 1당 10% 합산(소수점 버림, 최소 피해 0)
- 방어막: 카드 위력만큼 획득, 여러 공격 흡수, 턴 종료 소멸
- 회피: 카드가 연결된 빠른 보스 행동 시점에 조기 발동. 자신에게 도착하는 공격마다 회피 수치와 공격 위력 비교, 성공하면 유지 / 실패하면 소멸. 기존 회피보다 높은 값만 갱신
- 반격: 피격 이후 자신을 공격한 대상에게 1회. 방어막으로 모두 막아도 반격, 회피 성공 시에는 미발동
- 일반 키워드: 기존 키워드가 있으면 **명시된 위력/횟수만 추가**, 처음 부여할 때만 생략된 필드를 1로 초기화. 턴 종료 시 횟수 1 감소, 0이면 제거
- 신속·속박: 다음 턴 시작에 예약 활성화, 슬롯별 속도 판정 시 적용
- `ON_USE`, `ON_CLASH_START`, `ON_CLASH_WIN`, `ON_CLASH_LOSE`, `ON_CLASH_DRAW`, `ON_HIT`, `ON_EVADE_SUCCESS`, `ON_EVADE_FAIL`, `ON_BATTLE_START` 트리거
- 적중 시 취약은 피해 처리 뒤 부여되어 **다음 공격부터** 적용

## 핵심 파일

- `index.html`: 게임 화면, 배치 UI
- `styles.css`: 반응형 디자인
- `engine.js`: 전투 엔진과 캐릭터·카드 데이터
- `ui.js`: 브라우저 UI 이벤트 및 렌더링
- `tests.js`: Node.js가 설치된 경우 `node tests.js`로 실행하는 로직 검증

## 현 단계에서의 의도적 단순화 및 미확정 설계

- 특수 카드는 타입만 예약되어 있으며 상세 규칙 및 실전 카드는 구현하지 않았습니다.
- 카드 에너지, 드로우 수, 캐릭터 수, 보스 공격 패턴, 속도 범위는 **프로토타입용 임시 수치**입니다.
- 회피 성공은 `회피 수치 >= 공격 위력`로 처리합니다(기존 제안 기준).
- 공격 외 수비 카드는 보스의 공격과 연결될 때 즉시 발동되며, 대상 타격 처리 전 방어/회피/반격 상태가 활성화됩니다.
- 방어막 흡수 시 실제 체력 피해가 0이어도 공격이 적중했다면 `ON_HIT` 및 반격이 발동합니다.
- 소수점 피해는 버림, 카드 최종 위력은 최소 0, 속도는 최소 1로 제한합니다. 이는 프로토타입 기본값입니다.
- 한 보스 행동 슬롯에는 아군 1개의 대응 행동만 연결할 수 있습니다.
- 캐릭터가 전투 불능이 되면 해당 캐릭터의 남은 행동은 실행하지 않습니다.
- 보스의 방어 카드에는 공격 합을 직접 연결할 수 없으며 보스 본체를 공격하면 방어막이 적용됩니다.
- 모든 로직은 브라우저에서 실행되며 저장·로드·애니메이션·음악·멀티플레이는 아직 없습니다.

## 카드나 스킬 추가

`engine.js` 상단의 `HEROES` 배열 안에 다음 형식의 카드를 추가합니다.

```js
card('new1','새 스킬','ATTACK',12,'적중 시 대상 취약 2',[
  eff('ON_HIT','VULNERABLE',2,undefined,'TARGET')
])
```

`eff(트리거, 키워드, 위력, 횟수, 대상)`이며 대상은 `SELF` 또는 `TARGET` 등을 지정합니다. 일반 키워드의 위력/횟수 생략값은 **첫 부여 시에만** 1로 초기화됩니다.
