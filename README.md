# 심연 레이드 — TypeScript V6.0

V5.3을 기반으로 연속 공격·상태이상·카드 조작·손패 보충을 확장한 싱글플레이 레이드 카드게임 프로토타입입니다. **기존 아군 슬롯/보스 슬롯, 속도순 표시, 합 연결선, 특수 카드 즉시 발동, Vite 자동 캐시 무효화를 유지**합니다.

## 설치·실행·배포

Node.js 22 이상을 설치한 뒤 프로젝트 루트에서 실행하세요.

```powershell
npm install
npm test
npm run build
npm run dev
```

개발 중에는 Vite가 표시하는 로컬 URL(일반적으로 http://localhost:5173/)을 이용하세요. GitHub Pages는 `main` 브랜치 push 시 `.github/workflows/pages.yml`이 테스트와 빌드 후 `dist/`를 배포합니다. `vite.config.ts`의 `base: './'`는 GitHub Pages의 저장소 하위 주소에 맞춰져 있습니다. CSS/JS는 Vite에서 내용 해시 파일명으로 관리하므로 일반적인 구버전 캐시 충돌을 줄입니다.

## V6 신규 전투 규칙

### 연속 공격 (`MULTI_ATTACK`)

카드 정의에 `hitCount: 2~20`을 지정합니다. 합은 카드당 한 번, 실제 피해·회피·치명타·가호·파열·`ON_HIT`는 타격마다 판정합니다. 총 위력 P를 N타로 나누어, 몫은 모든 타격에 부여하고 나머지 1씩을 **마지막 타격부터 거슬러 올라가며** 배분합니다. 32위력 3타 = 10→11→11.

- 연속 공격에서도 `ON_USE`, 합 결과, `ON_ATTACK`(공격 시), `ON_ATTACK_END`(공격 후)는 카드 단위로 한 번 발생합니다. `ON_HIT_START`, `ON_HIT`, `BEFORE_DAMAGE`, `AFTER_DAMAGE`는 타격별로 발생합니다.
- 출혈과 독은 단일 행동 카드 사용 시 한 번, 연속 공격은 타격마다 적용됩니다. **출혈은 합 판정 중에는 발동하지 않습니다.** 출혈로 공격자가 사망해도 그 타격은 실행하고 다음 타격은 중단합니다. 독은 개별 타격 직전 성장 판정합니다.
- 회피 성공, 가호 무효화에서는 `ON_HIT` 및 파열이 발동하지 않습니다. 가호로 타격을 무효화해도 `ON_ATTACK`은 취소되지 않습니다.
- 연속 공격 중 공격자/대상이 사망하면 이후 타격은 중단됩니다.
- 예시 카드: 그림자 검객 `급소 절단` (3연속 공격), 보스 `파쇄 일격` (3연속 공격).

### 키워드

| 내부 ID | 효과 및 소멸 |
|---|---|
| `BURN` 화상 | 턴 종료 시 위력만큼 보호·취약 무시 고정 피해, 방어막 적용. 횟수 -1 |
| `BLEED` 출혈 | 카드 행동 발동 시 고정 피해, 횟수 -1. 연속 공격은 개별 타격마다. **턴 종료 감소 없음** |
| `RUPTURE` 파열 | 피격 시 위력만큼 고정 피해, 횟수 -1. 방어막에 막혀도 발동, 회피/가호 성공은 미발동. **턴 종료 감소 없음** |
| `POISON` 독 | 카드 사용 또는 연타 직전 성장 확률 `min(50, 위력+횟수)%`, 성공 시 양쪽 `min(5, floor((위력+횟수)/10)+1)` 증가. 턴 종료 시 위력만큼 **방어막도 무시**하는 피해, 횟수 -1 |
| `CORROSION` 부식 | 턴 시작 최대 HP×수치%의 **방어막 무시 직접 체력 감소**, 수치 -1 |
| `PARALYSIS` 마비 | 다음 공격/수비 카드 위력 -10, 수치 -1. 특수 카드는 영향/소모 없음 |
| `TAUNT` 도발 | 부여자 ID로 다음 턴 예약. 나중 예약된 도발로 덮어쓰기. 활성화 시 부여자 생존 여부 확인. 해당 턴 보스의 공격 대상 고정, 턴 종료 소멸 |
| `DISTRACTION` 사고 분산 | 다음 비특수 카드 위력 -수치, 사용 후 또는 턴 종료 소멸 |
| `DAMAGE_DOWN` 피해량 감소 | 가하는 피해 -10%×위력, 턴 종료 횟수 -1 |
| `LOCKDOWN` 봉쇄 | 다음 턴 속도 1로 고정, 활성 턴 종료 소멸 |
| `MANA_BACKFLOW` 마력 역류 | 보유 중 자연·효과 마력 회복 불가, 턴 종료 수치 -1 |
| `MANA_LEAK` 마력 누출 | 모든 카드 마력 비용 +수치, 턴 종료 소멸 |
| `MARK` 표식 | `MARK:부여자ID` 키로 개별 저장, UI `표식-캐릭터명`. 실제 효과는 캐릭터 설계 시 정의 |
| `BREATH` 호흡 | 적중 타격별 위력×5% 치명타, 성공 시 횟수 -1, 피해×1.2 |
| `REGEN` 재생 | 턴 시작 최대 HP×수치% 회복, 수치 -1 |
| `FOCUS` 집중 | 다음 비특수 카드 위력 +수치, 사용 후 또는 턴 종료 소멸 |
| `DAMAGE_UP` 피해량 증가 | 가하는 피해 +10%×위력, 턴 종료 횟수 -1 |
| `MANA_EFFICIENCY` 마력 효율 | 모든 카드 마력 비용 -수치, 턴 종료 소멸 |
| `BLESSING` 가호 | **적중한 개별 타격**을 완전 무효화(공격 피해·적중 효과·파열), 수치 -1. 턴 종료 소멸. 공격 시 효과는 유지 |
| `LIFESTEAL` 흡혈 | 실제 HP 피해량의 수치×10% 회복, 턴 종료 소멸 |

화상·출혈·파열·독은 보호·취약을 무시하며, **독 외에는 방어막으로 막을 수 있습니다**. 일반 공격의 최종 피해는 (1) 카드 위력 (2) 가하는 피해량 증가/감소 (3) 호흡 치명타×1.2 (4) 받는 보호/취약 (5) 방어막 (6) HP 적용 순서로 처리합니다. 최종 피해량은 소수점 버림입니다. 기존 키워드 위력·횟수 상한은 99입니다.

### 카드 조작 및 손패

- 손패가 턴 종료 시 7장을 초과하면 초과 장수만큼 **무작위로 버림 더미로 이동**합니다.
- 다음 턴 정상 드로우 후 손패가 **3장 미만이면**, 마력 1당 1장씩 최대 3장이 되도록 보충합니다. 원인은 검사하지 않고 마력/카드가 부족하면 가능한 만큼만 뽑습니다.
- `CREATE_CARD`: 전투 중 새 물리 카드 인스턴스를 만듭니다. `generated: true` 카드는 기본 사용 후 소멸 영역(`exhaust`)에 들어가며, `recycleGenerated: true`는 예외적으로 버림 더미에 들어갑니다.
- 효과 명령: 기존 7종 외 `SPEND_MANA`, `DISCARD_CARDS`, `CREATE_CARD`, `EXHAUST_CARD`, `TRANSFORM_CARD`, `MODIFY_CARD_POWER`, `MODIFY_CARD_COST`를 추가했습니다.
- `DISCARD_CARDS`의 `selection: 'RANDOM'`은 무작위, `'CHOOSE'`는 선택 대기열을 만들며 UI에 선택창을 표시합니다. 선택이 끝나기 전 다른 행동이나 다음 턴 진행을 막습니다. 장착된 카드는 선택 대상에서 제외됩니다.
- 카드 그림은 아직 넣지 않았습니다. `public/assets/cards/`에 파일을 추가하고 카드 데이터에서 `image: 'assets/cards/이름.png'`로 설정하세요. 직접 변경하는 이미지 파일은 파일명을 변경하면 캐시 문제가 줄어듭니다.

### 카드 데이터 예시

```typescript
const example = {
  id: 'combo_01', name: '삼연격', type: 'MULTI_ATTACK', power: 32,
  hitCount: 3, manaCost: 3, image: null,
  effects: [
    {trigger: 'ON_HIT', action: 'APPLY_KEYWORD', target: 'TARGET', keyword: 'RUPTURE', potency: 2, count: 1},
    {trigger: 'ON_ATTACK_END', action: 'HEAL', target: 'SELF', value: 2}
  ]
};
```

이미 구현된 일반 카드/특수 카드와 마력, 손패, 속도순 슬롯 정렬, 합 가로채기 규칙은 유지합니다. V6 예시 카드들은 기존 고정 덱의 일부 카드 효과를 시험용으로 확장했습니다.

## V6.1 — 메인 메뉴 / 캐릭터 도감 / 전투 화면 UI

- 시작 화면: **마법소녀들의 도시** 제목, 마법 소녀 / 전투 / 도감(개발 예정) 메뉴, 설정 팝업.
- `마법 소녀`: 27칸(3열 × 9행) 캐릭터 컬렉션. 오른쪽 이름 검색 / 보유 여부 / 사용 키워드 필터. 선택 시 캐릭터 상세 창(능력치, 고정 덱, 패시브).
- **중요:** 기존 엔진에 실제 데이터가 정의된 캐릭터는 6명뿐이므로 첫 6명만 실데이터를 사용하며, 나머지 21칸은 이름·능력·카드·이미지를 임의로 만들지 않은 `미공개 캐릭터` 자리 표시자다. 현재는 3명 초기 보유, 레이드 승리마다 남은 데이터 정의 캐릭터를 한 명씩 해금한다. 해금 상태는 브라우저의 `localStorage`에 저장된다. 27명을 모두 플레이 가능하게 하려면 향후 `src/engine.ts`에 데이터/덱/패시브/마력을 추가해야 한다.
- `전투`: 보유 캐릭터 편성 화면으로 진입. 기존 합 연결·드래그·손패·턴 실행 기능 유지.
- 전투 시안: 아군의 초록색 캐릭터 영역은 왼쪽, 붉은색 보스 영역은 오른쪽에 위치. 노란 육각형은 행동 슬롯의 **속도**, 캐릭터 아래 붉은색 바는 현재 HP. 보스 슬롯 호버 정보와 합 연결선 유지.
- 캐릭터 이미지는 아직 추가하지 않았으며, `public/assets/characters/`에 이미지를 넣은 다음 해당 영웅 데이터에 `portrait: 'assets/characters/파일명.png'`를 추가하면 표시할 수 있다. 카드 이미지는 기존처럼 `public/assets/cards/`에 배치한다.
- 설정 중 애니메이션 사용 토글은 UI의 움직임만 제어하는 임시 기능이다. 도감의 21개 미구현 캐릭터와 설정/도감의 향후 시스템은 작업 범위 밖이다.

실행: `npm install` → `npm run dev`; 배포 검사: `npm test` → `npm run build`.

## V6.2 — 한 화면 전투 UI / 슬롯 미리보기

- 전투 화면에서 브라우저 세로 스크롤을 사용하지 않고, 상단 전투장과 하단 손패/마력 영역이 화면 높이에 맞게 조절됩니다. 작은 화면에서는 손패 카드·마력/키워드 패널 **내부**에서 필요한 내용을 스크롤할 수 있습니다. 일반 메인/편성/도감 화면은 기존 스크롤 방식을 유지합니다.
- 아군의 행동 슬롯과 적의 행동 슬롯은 속도 숫자를 별도 육각형으로 유지하고, 슬롯 내부에는 **카드 이미지(미등록 시 아이콘)**만 표시합니다. 카드 이름과 효과는 슬롯에 포인터를 올리거나 키보드 초점을 맞췄을 때 확인할 수 있습니다.
- 슬롯 상세 정보는 슬롯 내 툴팁이 아닌 전투장 내부 **고정된 정보 패널**에서 표시합니다. 아군 슬롯은 왼쪽 상단, 적 슬롯은 오른쪽 상단입니다. 각 카드의 타입·위력·속도·소모 마력(아군)·효과 설명 및 보스 공격 대상(적)을 표시합니다.
- 기존의 카드 장착, 아군 슬롯 선택, 합 드래그 앤 드롭, 합 연결선, 특수 카드 사용, 전투 엔진과 키워드 규칙은 변경하지 않았습니다.
- 캐릭터 및 카드 이미지는 별도로 추가하지 않았습니다. 기존 `image`, `portrait` 필드가 설정되면 이를 사용합니다.

**검증:** `npm run typecheck`, `npm test` (103개) 통과. 이 실행 환경의 브라우저에서는 localhost 내비게이션이 차단되어 실제 Chrome/Edge 렌더링은 별도로 확인해야 합니다.

## V6.3 — 전투 중 캐릭터 정보

- 전투 하단에는 선택한 아군의 마력과 손패를 표시합니다. 아군이나 보스의 스프라이트를 선택하면 스프라이트가 확대되고 클립보드형 정보창이 열립니다.
- 요약은 덱·손패·버림 더미의 카드를 종류별로 집계합니다. 덱 탭에서는 각 카드에 포인터를 올리거나 키보드로 초점을 맞춰 효과 설명을 읽을 수 있습니다. 보스는 사용 가능한 기술을 표시합니다.
- 캐릭터에 패시브가 여러 개라면 `src/engine.ts`의 `PASSIVES` 항목에 카드 정의 배열을 지정합니다. 해당 발동 시점의 효과는 등록 순서대로 실행합니다. 기존 단일 카드 정의도 사용할 수 있습니다.
- 캐릭터 데이터의 `portrait`와 `sprite`에 각각 얼굴과 전투 이미지의 상대 경로를 지정할 수 있습니다. 예를 들어 `assets/characters/face.png` 파일은 `public/assets/characters/face.png`에 배치합니다.
